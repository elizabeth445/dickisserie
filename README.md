# DICKISSERIE

## Комментарии к элементам

В локальной версии (`npm run dev`) на компьютере доступен Agentation. Нажмите круглую кнопку справа внизу, затем нужный элемент страницы. Напишите замечание и нажмите **Add**. Кнопка **Copy feedback** копирует все замечания вместе с селекторами и найденными файлами компонентов — вставьте этот текст в чат Codex.

Сохранённую отметку можно нажать, отредактировать через **Save** или удалить. **Exit** возвращает обычное управление сайтом. Панель можно перетаскивать, а кнопкой **Pause animations** удобно остановить сцену для комментария. Заметки хранятся в текущем браузере до 7 дней; экспортируйте нужные правки перед очисткой данных браузера. Без endpoint и webhook ничего не отправляется автоматически. В production build панель отсутствует. На сенсорных устройствах она не показывается; мобильную компоновку можно комментировать в узком окне браузера на компьютере.

React + TypeScript + Vite сайт adult waffle & cocktail bar, основанный на предоставленном референсе. Интерфейс на английском; запланированы украинская и литовская версии. Hero использует HTML-типографику, пользовательское 4K-видео и фотографический фон.

## Запуск

Нужен Node.js 22.12+ и npm. Из корня репозитория:

```sh
npm ci
npm run dev
```

Адрес: **http://127.0.0.1:5173/**. Сервер слушает только loopback.

Сайт проверяется в Google Chrome в отдельном автоматизированном профиле.

## Проверки

```sh
npm run lint
npm run build
npm test
```

Playwright использует установленный Chrome и отдельные профили. Путь можно переопределить через `PLAYWRIGHT_CHROME_PATH`. При отсутствии системного Chrome понадобится браузер Playwright. Тесты покрывают корзину, сохранение/восстановление, некорректные данные, демо-заказ, native validation, клавиатуру, mobile navigation, reduced-motion, отсутствие ошибок и внешних запросов, axe и адаптивную геометрию. Скриншоты создаются в `output/screenshots/`; отчёты, trace, build и зависимости игнорируются Git.

Выполненные проверки, ограничения и профессиональная критика: `docs/QA.md`.

## Редактирование

- `src/data/products.ts` — названия, состав набора, цены, изображения, категории, описания. Цены относятся к предоставленному меню и не подтверждаются как текущие.
- `src/data/content.ts` — основные тексты, CTA и адрес.
- `src/styles/design-tokens.css` — семантические цвета и параметры системы.
- `DESIGN.md` — арт-дирекция, типографика, сетка и responsive-принципы.
- `ANIMATION_SPEC.md` — motion-сценарии и reduced-motion.
- `ASSETS.md` — происхождение и ограничения изображений.

## Демо-функции

Работают фильтры, выбор продукта, количество, localStorage-корзина и проверка тестового заказа с выбором окна самовывоза. Демонстрационный номер создаётся локально; затем корзина очищается. Заказ никуда не отправляется, деньги не списываются. Контактные и платёжные данные не запрашиваются и не сохраняются. LocalStorage хранит только версию схемы, известные product IDs и ограниченные количества.

Настоящие заказы потребуют подтверждённых цен, наличия, аллергенной информации, часов работы, серверного API и системы обработки заказов. Бронирование не имитируется. Instagram и Google Maps настроены в `src/data/content.ts`.

## Размещение

`npm run build` создаёт статическую сборку в `dist/`. Конфигурация Vercel находится в `vercel.json`; корень проекта — корень репозитория. Публикации запускаются вручную после явной команды пользователя; автоматические публикации при push отключены. Agentation включён только в локальной разработке.

Оригиналы материалов в `references/`, резервные копии и скриншоты проверок остаются локально. Для сборки сайта достаточно сохранённых ресурсов `public/assets/`; скрипты подготовки медиа требуют локальных оригиналов.
