# Проверка и критика

Дата: 22 ноября 2026. Сайт проверен локально в установленном Google Chrome, в отдельных профилях автоматизации; личный профиль не использовался.

## Выполнено

- `npm run lint`: без ошибок.
- `npm run build`: TypeScript strict и Vite production build без ошибок. Финальные JS около 380 kB, gzip около 130 kB; CSS около 29 kB. Используются только четыре нужных WOFF2, а не весь набор математических/символьных subset.
- Playwright: **29 passed, 4 skipped**. Пропуски — намеренные: мобильное меню не запускается в desktop/reduced проектах; viewport matrix не дублируется в двух других проектах. Нет отключённых из-за сбоя тестов.
- Полный путь: фильтр → продукт → количество → добавление → сохранение → reload → изменение/удаление → review → обязательное окно самовывоза → явное demo confirmation → пустая корзина.
- Проверены неверный JSON, неизвестные product IDs, отрицательные/дробные количества, запрет localStorage и предел 20 единиц. При невозможности сохранить данные корзина работает до закрытия страницы и показывает объяснение.
- Keyboard: Tab/Shift+Tab внутри native dialog, Escape, закрытие и возврат фокуса, блокировка фонового scroll. Mobile navigation закрывается при переходе к разделу.
- Axe: ноль обнаруженных нарушений в проверяемых WCAG A/AA правилах на основной странице и в заполненной корзине, в трёх проектах. Это автоматический аудит проверенных состояний, а не сертификация полной доступности.
- В функциональных тестах нет page errors, HTTP 4xx/5xx, неуспешных изображений или внешних runtime-запросов.
- Mobile/touch эмуляция Chrome, reduced-motion, desktop. Ширины: **320,375,390,428,768,1024,1440,1920px**. Проверены bounding boxes текста и управления, document overflow и реальные скриншоты каждого раздела.
- Better Design motion probe на 13 элементах меню и действий: **0 errors, 0 warnings** в обычном и reduced-motion режимах. Проверяет press/hover/focus/release; не заменяет просмотр движения.
- GSAP cleanup при последовательности ширин 1440→390→768→1440→390: количество ScrollTrigger **3→0→3→3→0**. Накопления нет.
- Секреты: source/config проверены на типовые ключи, токены и private-key blocks; совпадений нет. Нет `.env` и реальных интеграционных credentials. Remote repo, commit, push и deploy не выполнялись.

## Визуальный refinement

Первый desktop/mobile проход выявил грубые края маски и розовую подложку вокруг вафель: контуры переделаны. Режим multiply менял цвет молочной глазури — заменён прозрачностью внешнего фона с сохранением настоящих цветов. Мобильные CTA переведены в нормальный flow, а не привязаны к фиксированным координатам.

Независимый reviewer получил только DESIGN.md и скриншоты. Swap test прошёл: конкретная связка вафель, зелёного мрамора, halftone-портрета и Bodoni специфична для DICKISSERIE. По review название и цена на mobile подняты над фотографией; фото стало ниже, Add to bag поднята перед списком. Для широкого экрана натюрморт ограничен 700px. Исправлен способ снимка первого экрана, чтобы включать header, и увеличен мобильный верхний отступ masthead.

Дополнительно исправлены контраст кнопок (ivory на #CE0054 ≈4.76:1), Tab containment, ширина промежуточной композиции и нативное accessible name корзины. Финальные product/checkout состояния осмотрены отдельно от полных страниц.

Геометрический `check_layout.py` запускался на DOM dumps 320,390,768,1024,1440,1920px. Его эвристики выдали замечания, включая длинную страницу за пределами viewport, намеренные image crops, разную ширину цен, центрирование glyph ink и близость краёв несвязанных секций. Этот raw checker **не объявлен пройденным**. Реальная проблема inline-контейнера wordmark исправлена `display:block`; горизонтальный fit и доступность управления проверены отдельными Playwright assertions и визуально. Декоративный collage исключён из семантического geometry scan намеренно.
