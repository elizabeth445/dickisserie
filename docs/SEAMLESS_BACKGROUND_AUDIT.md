# Непрерывный бархатный фон

## Итог

После уточнения пользователя фотографическая ткань продолжается по всему сайту, а не затухает к однотонной зелёной заливке. Header, Hero, Menu, The Bar, Find Us и Footer лежат над общим полотном. Композиция, тексты, продукты и обработчики навигации сохранены.

## Найдено и исправлено

| Участок | Причина | Решение |
| --- | --- | --- |
| Header → Hero | Исходное фото занимало 92% высоты, сверху проступала заливка; на mobile фотография начиналась под заголовками | Продолжена верхняя пустая фактура, Header прозрачный. Один picture Hero проходит под навигацией |
| Hero → Menu | Короткое затухание и отдельный прямоугольный crop бархата в меню | Удалён локальный crop. Неподвижная маска Hero соединяет фото с общим фотографическим полотном |
| Menu → The Bar | Фотографический фон существовал только в Hero | Общий фон проходит за обеими секциями без отдельной заливки |
| The Bar → Find Us → Footer | Однотонные заливки обрывали ткань | Заливки прозрачны, единый рисунок складок продолжается до нижнего края страницы |

Рамки продуктов, закруглённые фотографии интерьера и тонкая разделительная линия перед Find Us намеренные; они сохранены.

## Устройство

- `.site-backdrop` — одно изображение на всю высоту документа, без повторения, fixed/sticky и собственного scroll-цикла. Все основные секции прозрачны.
- `continuous-velvet.avif` с WebP fallback получен из исходного фрагмента ткани через imagegen. На нём нет продуктов и текста. Мастер 724×2172 сохранён; CSS cover сохраняет пропорции.
- Деликатное равномерное затемнение 24% сохраняет читаемость и видимую фактуру. Нет blur, glow или тумана.
- Маска Hero неподвижна: 144px desktop, 64px mobile. ScrollTrigger двигает изображение внутри неё; край маски не перемещается.
- Верхнее outpainting выполнено по пустой полосе исходного Hero. При сборке оригинальная фотография возвращена поверх нижней части: пиксели от y=155 до конца исходника полностью совпадают с master, проверено сравнением raw buffers. Вафли, бокал и композиция не перегенерированы.
- Экспорт: `node scripts/extend-hero-background.mjs`. Исходники в `references`, результат в `public/assets`.

## Проверки

Локальный Google Chrome через проектный Playwright; mobile — эмуляция, не физические телефоны. Дополнительно использован Chrome DevTools MCP для просмотра и консоли.

- Осмотрены все четыре перехода на 375, 390, 1440 и 1920px. Скриншоты до и после сохранены для каждого.
- Горизонтальное переполнение при проходе по всей странице: 0px на всех четырёх ширинах. Проектная responsive-матрица дополнительно охватывает 320, 428, 768, 1024, 1280 и 1600px.
- Проверен плавный anchor-scroll при `no-preference`: промежуточные позиции меняются постепенно на всех четырёх ширинах. При reduced motion переход мгновенный по существующим настройкам.
- Фон прокручивается вместе с документом; отдельные секции не меняют его положение и оттенок. Видео отсутствует.
- `npm run lint` и production build проходят.
- Playwright: 29 passed, 4 intentional skips. Проверены фильтры, корзина, demo checkout, клавиатура, мобильная навигация, persistence, reduced motion, axe и загрузка локальных ресурсов.
