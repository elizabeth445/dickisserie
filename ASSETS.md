# Происхождение материалов

## Актуальные Hero и общее полотно

- `references/hero-motion-upscaled-3x.mp4` — новый переданный пользователем мастер 3840×2160, 9.9с. Рабочие версии обрезаны до 7.9с: `hero-motion-4k.mp4` без повторного сжатия видеопотока, `hero-motion-1080.mp4` и `hero-motion-720.mp4` из этого же мастера. Без звука и служебных метаданных. `hero-motion-first.webp` — poster 1920px. Старый 720p-исходник сохранён как `references/hero-motion-original.mp4`. Подготовка и проверка: [HERO_VIDEO.md](docs/HERO_VIDEO.md).
- `references/hero-scene-supplied.png` — переданная полная фотография. `references/masters/hero-scene-extended.png` сохраняет все продуктовые пиксели оригинала; AI продолжает только пустой верхний фон. Runtime: `hero-scene-extended*.avif` и WebP.
- `references/masters/continuous-velvet.png` — фотографическая ткань, продолженная imagegen по фрагменту исходного бархата. Runtime: `continuous-velvet.avif` и WebP, единый фон всей страницы. Продукты в этом изображении отсутствуют.
- `references/waffle-trio-supplied.png` — пользовательский прозрачный продуктовый снимок; runtime `waffle-trio*` для меню. Остальные фотографии упаковок и интерьерные визуализации сохранены из пользовательских материалов.

Кадры `screenshots/video-source-*.png` служат только для просмотра и QA старого исходника. Анимация не собирается из PNG. Новый 4K-файл предоставлен пользователем как версия с апскейлом 3×; это не исходная съёмка в 4K.

## Архив ранней сборки

Ниже сохранено происхождение материалов ранней версии. Портрет, отдельный бокал, gift-box и SVG-жидкости из этой версии удалены из текущего Hero.

Все брендовые изображения предоставлены пользователем. Права на их публикацию отдельно не проверялись: задача выполняется локально. Исходники сохранены в `references/`; в браузер попадают только оптимизированные файлы `public/assets/`.

| Исходник | Рабочие файлы | Использование |
|---|---|---|
| `references/hero-reference.png` | `waffle-still-life.webp`, `portrait.webp`, `cocktail.webp`, `gift-box.webp` | Отдельные прозрачные локально выделенные слои. Исходный скриншот не служит фоном интерфейса |
| `references/brand-logo.png` | `monogram.webp`, `favicon.png` | Фирменная монограмма из исходного логотипа, без замены сторонним знаком |
| `references/dick-box.png` | `dick-box.webp` | Фотография коробки с тремя вафлями; текст цены с фотографии удалён кадрированием |
| `references/pussy-box.png` | `pussy-box.webp` | Фотография формы Pussy Waffle; для смешанного варианта отдельной фотографии нет, это указано в подробностях |
| `references/mixed-box.png` | `mixed-box.webp` | Фотография двух Dick Waffles и трёх мини |
| `references/single-pack.png` | `single-pack.webp` | Индивидуальная упаковка; исходное фото показывает два образца упаковки, продаётся одна вафля |
| Фрагмент мини-вафель главного референса | `mini-waffles.webp` | Категория и продукт 9 pcs. Исходник маленький, максимальный размер в галерее ограничен 300px. Для production желательно оригинальное фото набора из 9 штук |
| `references/DICKISSERIE_albom.pdf`, стр. 4 | `interior-bar.webp`, `interior-bar-640.webp` | Интерьерная визуализация, не документальная фотография |
| Тот же PDF, стр. 15 | `bar-editorial.webp`, `bar-editorial-640.webp` | Визуализация коктейля и десерта; контекст обозначен в alt и подписи |
| Fontsource Bodoni Moda, DM Sans | Локальные WOFF2 через Vite | Оригинальные OFL-лицензии в `public/assets/font-licenses.txt` |

Подготовка: детерминированное кадрирование и маски контуров, прозрачность фона, WebP. Цвет настоящей глазури сохранён: multiply-blending не применяется. Для интерьерных изображений есть responsive srcset. Hero pastry имеет preload; все крупные нижние изображения lazy-loaded и имеют размеры.

Попытка обработки референса встроенным imagegen была отклонена инструментом. Сгенерированные изображения не используются. Портрет и продукты — части исходных пользовательских материалов. Отдельные SVG жидкости созданы кодом и масштабируются в координатах изображений.
