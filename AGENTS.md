# DICKISSERIE

- Общение на русском. Сейчас интерфейс на английском; для проекта запланированы три языковые версии: украинская (UA, код локали `uk`), литовская (LT, `lt`) и английская (EN, `en`). Сначала читай DESIGN.md и текущие файлы.
- Валюта всех языковых версий — евро (EUR). Формат цен утверждён пользователем: UA и LT — `17 €`, `17,50 €` (знак после числа, десятичная запятая); EN — `€17`, `€17.50` (знак перед числом, десятичная точка).
- Целые цены показывать без десятичной части, дробные — с двумя знаками; дробные цены не округлять до целых. Между суммой и € в UA/LT использовать неразрывный пробел. При реализации языковых версий применять эти правила через единый форматтер ко всем ценам: меню, карточкам, кнопкам, корзине, итогам и подтверждениям.
- Сохраняй выбранный editorial collage: emerald #00180F, ivory #F7EBDD, hot pink #F00062, blush #F3B1C3. Кнопки #CE0054 нужны для контраста 4.76:1 с ivory.
- Bodoni Moda Variable для wordmark, Newsreader Variable для заголовков, DM Sans Variable для UI. Шрифты self-hosted; сохраняй текущую идентичность.
- Hero — предоставленная пользователем фотография с настоящими HTML-текстом и кнопками. Общая фотографическая ткань `.site-backdrop` продолжается по всему сайту до Footer; не возвращай отдельные зелёные заливки и прямоугольные обрывки текстур. См. docs/SEAMLESS_BACKGROUND_AUDIT.md. Продукты не перегенерировать.
- Hero воспроизводит новый пользовательский мастер `hero-motion-upscaled-3x.mp4` (3840×2160), обрезанный до 7.9с: последние 2с исключены. Desktop использует 4K без повторного сжатия, меньшие экраны — Full HD, медленная сеть — 720p. Сохраняй pause/replay, offscreen/visibility pause, reduced-motion и Save-Data. См. docs/HERO_VIDEO.md и scripts/prepare-hero-video.mjs.
- Никаких шаблонных карточных блоков, декоративной нумерации/счётчиков, eyebrow-заголовков, декоративных слешей, ложных отзывов или неподтверждённых фактов.
- Контент и цены редактируются в src/data. Checkout явно демонстрационный, без передачи заказов. Не сохраняй контакты/платёжные данные.
- В интерфейсе не ставить точки в конце заголовков, подписей, предложений и сообщений, включая мобильную версию, карточки и корзину. Для разделения фраз использовать тире, переносы строк или другой подходящий знак; сохранять точки в дробных ценах EN, адресных сокращениях и URL.
- GSAP через scoped useGSAP и matchMedia с cleanup. Нет бесконечных loops и scroll hijacking. Поддерживай prefers-reduced-motion.
- Только локально. Не создавай remote repo, не делай commit, push, deploy без новой явной команды пользователя.
- По явному запросу пользователя Agentation включён и локально, и на опубликованном сайте. Основной модуль редактора загружается отдельно только на устройствах с мышью. Экспорт Copy feedback пользователь присылает вручную. Не подключать MCP endpoint/webhook и автоматическую отправку без отдельного запроса. Режим работает на компьютере; сохраняй нормальную навигацию при Exit и поддержку native dialog через portalContainer.
- После правок: lint, TypeScript/production build, подходящие Playwright-проверки. Для визуальных изменений осмотри реальные mobile/desktop screenshots, включая 320,390,768,1024,1440px; дополнительные цели 375,428,1920px.
- Проверяй клавиатуру, Tab containment, Escape, focus return, native validation, touch и ошибки консоли. Не объявляй проверки выполненными без запуска.
- Не удаляй исходники references. Не коммить node_modules, dist, output, тестовые отчёты, секреты или временные файлы.
